# Web – Silvestr na chalupě

## Soubory
- `index.html` – obsah webu a SEO metadata
- `styly.css` – vzhled webu, responzivní zobrazení
- `script.js` – mobilní navigace a příprava e-mailové poptávky

## Jak web otevřít
Otevřete `index.html` v prohlížeči. Všechny tři soubory musí zůstat ve stejné složce.

## Co upravit před zveřejněním
1. Nahraďte všechny údaje v hranatých závorkách skutečnými informacemi.
2. V `script.js` nahraďte `DOPLNIT-EMAIL@example.cz` skutečnou kontaktní adresou.
3. Přidejte vlastní fotografii jako `images/chalupa-hero.jpg` (vytvořte složku `images`) nebo změňte cestu v `styly.css`.
4. Doplňte zásady ochrany osobních údajů a odkaz na ně ve formuláři.
5. Formulář aktuálně otevře e-mailový program; neukládá ani neposílá poptávky na server. Pro automatické přijímání poptávek bude potřeba formulářová služba nebo server.
6. Před zveřejněním ověřte termín, cenu, kapacitu, vybavení, podmínky a dostupnost.

Web je pracovní šablona, ne hotový rezervační systém. Neznámé vlastnosti chalupy nejsou domýšlené.
